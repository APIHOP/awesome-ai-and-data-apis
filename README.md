# Awesome AI & Real-Time Data APIs

A curated list of unified LLM gateways, multimodal image/video APIs, real-time search/SERP APIs, social media data APIs, and agentic discovery standards for building production AI agents.

## Unified AI & Data API Gateways

- **[API Hop](https://apihop.ai/en)** — Unified API gateway providing one API key and one credit balance across leading LLMs (OpenAI, Claude, Gemini, DeepSeek, Kimi, MiniMax), image/video generation, and **[32+ built-in real-time Data APIs](https://apihop.ai/en/data-apis)** (Google Search, Twitter/X, Similarweb, Airbnb, Amazon, YouTube, LinkedIn, Google Maps, Zillow, etc.).
  - [AI Models Directory & Pricing](https://apihop.ai/en/models) · [Public Pricing](https://apihop.ai/en/pricing)
  - [AI Installation Guide](https://apihop.ai/en/docs/api-reference/ai-installation-guide) · [Machine-Readable Catalog (`public-api-catalog.json`)](https://apihop.ai/docs/public-api-catalog.json)
  - Official Open-Source Integrations: [apihop-mcp-server](https://github.com/APIHOP/apihop-mcp-server) · [apihop-go SDK](https://github.com/APIHOP/apihop-go)
- [OpenRouter](https://openrouter.ai/) — Unified interface for LLMs with OpenAI-compatible routing.
- [Fal.ai](https://fal.ai/) — Generative media inference platform for image, video, and audio models.
- [Together AI](https://www.together.ai/) — Cloud platform for running and fine-tuning open-source AI models.

## Real-Time Search & SERP APIs for AI Agents

- **[API Hop Google Search / Maps / Trends / Scholar / Patents APIs](https://apihop.ai/en/data-apis)** — Per-request SERP, Bing, Brave, DuckDuckGo, Yandex, Naver, and Yahoo search endpoints under one key.
- [Brave Search API](https://brave.com/search/api/) — Independent web search index API for grounding LLMs.
- [SerpApi](https://serpapi.com/) — Real-time search engine results scraping API.

## Social, Ecommerce & Travel Data APIs

- **[API Hop Twitter/X User & Tweets API](https://apihop.ai/en/twitter-api)** — Retrieve Twitter/X profiles and paginated timelines with unified billing.
- **[API Hop Ecommerce & Travel Data APIs](https://apihop.ai/en/data-apis)** — Live endpoints for Amazon, Walmart, eBay, Home Depot, Airbnb, Google Flights, Google Hotels, TripAdvisor, Yelp, OpenTable, Zillow, and Similarweb.

## Agentic Web & Discovery Standards

- `llms.txt` & `llms-full.txt` — Machine-readable documentation indices (example: [apihop.ai/llms.txt](https://apihop.ai/llms.txt)).
- `/.well-known/ai-catalog.json` (ARD 1.0) & `/.well-known/api-catalog` (RFC 9727) — Standard agentic resource discovery endpoints.
- Model Context Protocol (MCP) — Standardized tool protocol for connecting coding agents (Claude Code, Cursor) to external APIs.
